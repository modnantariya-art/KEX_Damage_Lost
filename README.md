# NIM Claim · ระบบเคสสินค้าเสียหาย / สูญหายจาก KEX

ระบบสำหรับทีม Claim ของ NIM Express ใช้บันทึก ติดตาม และวิเคราะห์เคสจาก KEX

ระบบมี 3 ส่วน

| ส่วน | อยู่ที่ไหน | หน้าที่ |
|---|---|---|
| `index.html` | GitHub Pages | หน้าโปรแกรม 4 หน้า ได้แก่ Dashboard, รายการเคส, เปิดเคส และกระทบยอดเงิน |
| `sheet-connector/Code.gs` | Google Sheet > Extensions > Apps Script | ตัวเชื่อมที่รับส่งข้อมูลระหว่างหน้าเว็บกับ Sheet |
| `KEX_Claim_Tracker` | Google Drive | ที่เก็บข้อมูลทั้งหมด |

---

## ติดตั้งครั้งแรก

### 1. เตรียม Google Sheet
1. อัปโหลด `KEX_Claim_Tracker.xlsx` ขึ้น Google Drive แล้วเปิดไฟล์ จากนั้นไปที่ **File > Save as Google Sheets**
2. ลบแถวตัวอย่าง ได้แก่ ชีต `Cases` แถว 5 และชีต `Followups` แถว 3 (คลิกขวาที่เลขแถว แล้วเลือก Delete row)
3. ในชีต `Lists` ให้พิมพ์รายชื่อทีม Claim ในคอลัมน์ O, รายชื่อ DC ในคอลัมน์ P และ Hub ของ KEX ในคอลัมน์ S
4. **ห้ามเปลี่ยนชื่อชีต** และห้ามแก้แถวชื่อคอลัมน์ภาษาอังกฤษ

### 2. ติดตั้งตัวเชื่อม
1. ใน Google Sheet ไปที่ **Extensions > Apps Script**
2. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ `sheet-connector/Code.gs`
3. แก้บรรทัด `var TEAM_PASSWORD = 'เปลี่ยนรหัสนี้';` ให้เป็นรหัสผ่านของทีม แล้วกด **Save**
4. กด **Deploy > New deployment > รูปเฟือง > Web app** แล้วตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด **Deploy** แล้วกด **Authorize access** เลือกบัญชีของคุณ
   - ถ้าขึ้นหน้า "Google hasn't verified this app" ให้กด **Advanced > Go to … (unsafe)** ได้ เพราะเป็นโค้ดของเราเอง
6. คัดลอก **Web app URL** ซึ่งขึ้นต้นด้วย `https://script.google.com/macros/s/…/exec`
7. ทดสอบโดยวางลิงก์นี้ในเบราว์เซอร์ ถ้าเห็นข้อความ `ตัวเชื่อม KEX Claim ทำงานปกติ` แปลว่าใช้ได้

### 3. ผูกหน้าเว็บกับ Sheet
เปิด `index.html` ด้วย Notepad หรือแก้บน GitHub ก็ได้ หาบรรทัดนี้

```
var API_URL = '';
```

แล้ววาง Web app URL ระหว่างเครื่องหมาย `' '` ให้เป็นแบบนี้

```
var API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

### 4. ฝากหน้าเว็บบน GitHub
1. สร้าง repo ใหม่แบบ **Public**
2. อัปโหลดไฟล์ `index.html` (และ README.md ถ้าต้องการ)
3. ไปที่ **Settings > Pages > Branch: main / (root) > Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

### 5. ส่งให้ทีม
- ส่ง **ลิงก์ GitHub Pages** และ **รหัสผ่านทีม** ให้ทีม Claim
- ทุกคนใส่รหัสครั้งแรก แล้วเลือกชื่อตัวเอง ชื่อนี้จะถูกบันทึกในประวัติการแก้ไข
- ทีม **ไม่ต้อง** มีสิทธิ์เปิด Google Sheet เพราะคนที่แก้ Sheet ได้มีแค่เจ้าของไฟล์

## งานประจำ
- **สิ้นเดือน:** ในชีต `สรุปรายเดือน` คอลัมน์ B ให้ใส่จำนวนพัสดุที่ส่งผ่าน KEX ของเดือนนั้น Dashboard จะคำนวณเคสต่อ 1,000 ชิ้นให้เอง
- **มีคนเข้า/ออกทีม:** แก้รายชื่อในชีต `Lists` คอลัมน์ O ถ้ามีคนออก ควรเปลี่ยนรหัสผ่านทีมด้วย

## เปลี่ยนรหัสผ่าน หรืออัปเดตตัวเชื่อม
1. แก้ `Code.gs` ใน Apps Script แล้วกด Save
2. กด **Deploy > Manage deployments > รูปดินสอ > Version: New version > Deploy**
3. ลิงก์ตัวเชื่อมยังเป็นลิงก์เดิม ไม่ต้องแก้ `index.html` แต่ถ้าเปลี่ยนรหัสผ่าน ทุกคนต้องเข้าสู่ระบบใหม่

## อัปเดตหน้าเว็บ
อัปโหลด `index.html` ไฟล์ใหม่ทับใน GitHub แต่ต้องคงบรรทัด `API_URL` เดิมไว้

## ข้อควรรู้
- ลิงก์ตัวเชื่อมกันคนนอกด้วยรหัสผ่านทีม อย่าเผยแพร่รหัสนี้
- ถ้าเข้าไปแก้สถานะเคสตรง ๆ ใน Sheet ต้องแก้วันที่ในคอลัมน์ "วันที่เปลี่ยนสถานะล่าสุด" ด้วย ไม่อย่างนั้นการนับ SLA จะคลาดเคลื่อน
- ไฟล์รองรับ 1,000 เคสในตารางสรุปของ Sheet ถ้าเคสใกล้ถึงจำนวนนี้ ต้องขยายช่วงสูตร
